  <h3>About the Project</h3>
  <p">The development of a logistics database system arises from the water refilling station, Aqualine, and their need to adhere to new means of business operations as opposed to traditional methods. Currently, one instance of these traditional methods is the manager manually facilitating the customers’ orders via phone calls and subsequently relaying instructions to the staff. With the integration of a logistics database system, the system aims to optimize Aqualine’s business workflows to be more efficient, more reliable, and more secure as intended.</p>
